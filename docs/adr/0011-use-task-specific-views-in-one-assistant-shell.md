# Use task-specific views in one Assistant Shell

The Guided Research Assistant will remain one floating website surface, but its internal view will match the selected Research Task instead of forcing every workflow into chat bubbles. Paper Question Mode retains a conversational view, and the Demo Profile task expands into a staged wizard with fixed navigation. Visualization Destinations open in the current tab and collapse the Assistant so the full page owns the visual interaction; tab-scoped sessions remain available when the Assistant is reopened. On mobile the shell uses a full-screen, single-column layout with fixed task navigation and bottom actions above the safe area or software keyboard, while remaining part of the current page rather than a separate application route.
