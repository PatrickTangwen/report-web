# Show aggregate neighborhood callouts instead of reference-patient cases

Embedding callouts will describe Matched Reference Neighborhoods and Display Regions with privacy-reviewed aggregates rather than individual Reference Patient identifiers or complete clinical values. A Query Patient may see their own confirmed inputs during the current browser session, but reference-point hover and annotations remain display-safe, small groups suppress sensitive aggregates, and profile or matching data is not placed in public URLs, analytics, or long-lived browser storage. This preserves the annotated visual style without turning anonymized UK Biobank records into reconstructable case profiles.
