# Present matched-reference context with the visualization

After the visitor reviews a Profile Draft and selects Confirm and compare with reference cohort, the Guided Research Assistant will run the comparison and automatically hand a Matched Reference Neighborhood to the destination visualization page. The Assistant then collapses so it does not obscure the visualization, while its tab-scoped Profile Session remains available for resuming or starting over. The destination remains chart-first: it highlights the matched references and shows only a Matched Reference Summary containing the target, matched count, and privacy-permitted median age and sex distribution. It does not render a full results panel, risk score, confidence, similarity percentage, full Profile Coverage, or detailed aggregate report. A No Stable Neighborhood remains in the Demo Profile Wizard and does not open a visualization. The explicit confirmation action provides the visitor authorization for a matched-result transition.
