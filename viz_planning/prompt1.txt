## 3. Specific interaction requirements
请重点考虑以下交互：

### UMAP / t-SNE patient embedding
- 每个点代表一个 patient
- hover tooltip 展示 patient-level summary，例如 patient id、age、sex、disease status、risk score、cluster assignment 等
- 支持 zoom in / zoom out / pan
- 支持按 disease、sex、age group、risk group、cluster 进行 coloring
- 支持点击单个 patient 后打开 patient detail panel
- detail panel 中展示该 patient 的 disease status、top risk factors、model prediction、nearest cluster / similar patients
- 如果是 use case 页面，点击 patient 后可以触发或展示 agent-style explanation：该 patient 属于哪个 disease-related cluster，主要依据是什么

### ICD code embedding
- 每个点代表一个 ICD-10 code
- hover tooltip 展示 ICD code、description、ICD chapter、frequency、related disease group
- 支持 zoom / pan
- 支持按 ICD chapter coloring
- 支持点击某个 ICD code 后展示相关 patient cohort 或 co-occurring codes
- 可以考虑 cluster-level summary

### Evaluation metrics comparison
- 用于展示不同模型在多个任务 / disease / metric 上的表现
- 不要做成商业 leaderboard
- 推荐更 academic 的 comparison table + compact bar / dot plot / heatmap
- 支持按 task、metric、model family 筛选
- 支持查看 confidence interval / standard deviation / p-value，如果论文中有相关数据
- 点击某个模型或任务后展示 detailed breakdown

### Ablation study
- 目标是说明不同模块或设计选择对性能的影响
- 推荐使用 grouped bar chart、delta plot、line chart 或 small multiples
- 重点突出“移除某模块后性能如何变化”，而不是单纯排名
- 支持选择 metric / task / disease
- tooltip 展示 full setting、metric value、delta from full model
- 如果可以，设计一个 explanation area，用文字解释主要 ablation conclusion

### Use case: 7 fibrotic diseases
- 展示 patient embeddings coloured by true first-onset fibrotic disease
- hover 展示 patient summary
- 点击 patient 后展示该 patient 的 disease prediction / disease status / risk factors
- 点击 cluster 后展示该 cluster 的 dominant disease composition、representative patients、risk profile

### Risk factor ranking / feature importance
- 展示 global feature importance 和 patient-specific explanation
- 支持切换 disease type
- 支持切换 global vs individual patient
- 推荐 bar chart / ranked list / lollipop chart
- tooltip 展示 feature name、importance score、direction、clinical interpretation
- 如果和 patient embedding 联动，点击 patient 后更新该 patient 的 feature ranking

### Pathway enrichment analysis
- 展示 pathway-level enrichment results
- 推荐 dot plot / bubble plot / ranked table
- 支持按 disease / cluster / feature group 筛选
- tooltip 展示 pathway name、p-value、adjusted p-value、gene count、enrichment ratio
- 点击 pathway 后展示 involved genes / related risk factors
